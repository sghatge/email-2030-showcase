## Safety boundary
All demonstrations remain synthetic. Do not use real recipient data, credentials, client content, or live platform connections. Skills cannot send email, alter suppression/consent, deploy templates, or trigger journeys. Existing QA and human approval gates remain required.

Pin and audit upstream content before importing into a separate namespace. Preserve all demo folders and run `./run_tests.sh` before enabling any routing.
