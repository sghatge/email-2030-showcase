# Post 1: Prompt to journey

2030 shift: you describe the journey in plain English, an agent drafts it, a human approves.

Adobe's Journey Agent in Journey Optimizer already offers a natural-language interface to create, analyze and optimize journeys (see Adobe Experience League, "Adobe Experience Platform Agent Orchestrator").

This demo is NOT that. It is a rule-based stand-in (no LLM) that turns a brief into a structured spec and lists open questions, to show the shape of the handoff.

Run: `python demo.py` | Test: `python -m pytest -q`
